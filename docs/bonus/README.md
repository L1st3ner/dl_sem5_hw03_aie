# Бонусная часть

В бонусной части предлагается **4 альтернативных задания** (B1–B4). Выберите **одно** из них. Максимальная оценка за бонусное задание — **4 балла**.

В `student.json` для выбранного варианта  в поле `"bonus"` укажите его название для автотестов:

| Вариант  | Название    |
|----------|-------------|
| B1. Embedding Drift Detection | `"b1_drift"` |
| B2. Knowledge Distillation: сжатие ViT для edge-deployment | `"b2_distillation"` |
| B3. Предсказание Property по SMILES: Transformer vs baseline на маленьком датасете | `"b3_smiles_property"` |
| B4. Multi-Task Learning: классификация + pseudo-NDVI на EuroSAT | `"b4_multitask"` |

В таблице ниже приведено короткое описание каждого бонусного варианта.

| Вариант | Направление | GPU | Артефакты |
|---|---|---|---|
| **B1** | MLOps / ML Monitoring | Нет | Нет |
| **B2** | Model Compression / Edge AI | Да | Да |
| **B3** | AI for Science / Cheminformatics | Нет | Да |
| **B4** | Multi-Task Learning / Efficient Inference | Да | Да |
